# DarWinWin

## Fast, multithreaded Neural Network with Genetic Algorithm for Ecosystem Simulation.

AI-Actors are trained to survive in a procedural generated Ecosystem.

Neural Network with Scoring Function and Genetic Algorithm with Crossbreeding and Mutation with parameter selection of the mutation parameters (chance, rate).

Fast, multithreaded.

The simulation includes movement of the actors, eating and pulling items whilst facing the threat of starvation, drowning.

Web Interface for visualization.

### How to generate project files:
- Run `create_project.bat`
- Select `1. Visual Studio 2022 Solution`
