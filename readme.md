# DarWinWin

## Fast and multithreaded Neural Network with Evolutionary Algorithm for Ecosystem Simulation.

AI-Actors are trained to survive in a procedural generated Ecosystem.

Neural Network with Scoring Function and Evolutionary Algorithm with Crossbreeding and Mutation with parameter selection of the mutation parameters (chance, rate).

Fast and multithreaded.

The simulation includes movement of the actors, eating and pulling items whilst facing the threat of starvation, drowning.

Web Interface for visualization.

## How to start the server:
- Open project solution in Visual Studio
- Compile and run the project
- Queries will be processed on port `21110`

## How to generate project files:
- Run `create_project.bat` from the commandline
- Select `1. Visual Studio 2022 Solution`
